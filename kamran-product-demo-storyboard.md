# KAMRAN Product Demo Storyboard

## Creative brief

Create a polished 75–90 second, 16:9 product-demo video for the real KAMRAN React Native app. Keep the mobile UI as the visual focus inside a clean modern smartphone frame. Use KAMRAN’s existing white, cobalt-blue, slate, and warm-neutral palette; preserve its English, Uyghur, and Chinese labels. Use restrained motion, realistic touch timing, and no claims beyond the implemented features. No voiceover is required; use subtle non-distracting background music only if available.

## Sequence

| Time | Authentic app flow | Visual direction | On-screen callout |
|---|---|---|---|
| 0–7s | Launch on the existing KAMRAN onboarding screen | Slow push-in on the blue spark icon, Uyghur–Chinese language pill, and “Speak freely.” headline; show the real Continue control | KAMRAN · Uyghur ↔ Chinese |
| 7–25s | Open Translate and enter a short sample phrase | Show the actual language selector, dialect selector, source input, and Translate action; tap once, show the real thinking/loading state, then reveal the translated result | Text translation · Clear results |
| 25–38s | Demonstrate voice input and playback controls | Show microphone permission/readiness surface only if present; tap voice input, show listening/processing animation, reveal recognized text, then show the speaker/playback control | Voice input · Listen back |
| 38–53s | Open OCR and capture text | Show the camera/OCR screen, scanning state, confidence/review state, editable detected text, and translation result; preserve the real permission/error recovery copy if encountered | Camera OCR · Review before translating |
| 53–67s | Open Learn | Show cultural lesson cards, open one lesson, mark it complete, and show progress feedback; use existing lesson copy and no invented statistics | Learn the context |
| 67–78s | Open History | Show saved translations, favorites, session-only behavior if configured, and the fallback-result disclosure only when a fallback result is actually present | History · Favorites |
| 78–86s | Open Settings and close | Show Save translation history, voice preferences, cultural-progress summary, and the retry/recovery affordance only when applicable; end on a calm KAMRAN brand frame | Built for everyday conversations |

## Fidelity rules

Every screen and interaction must come from the implemented KAMRAN project. Do not fabricate network responses, permissions, statistics, account screens, or App Store claims. Preserve the app’s actual copy, typography, iconography, and language direction. If a native permission prompt cannot be captured, use the app’s real readiness or recovery state rather than simulating a system dialog. If a service fallback is shown, label it as a fallback result and keep the review warning visible.

## Production constraints

Use a realistic portrait-device frame in a clean 16:9 presentation composition. Keep UI text sharp and readable, use gentle pans and zooms only, and avoid excessive transitions. The target export is a high-quality MP4 between 75 and 90 seconds. The opening should remain recognizable as the actual onboarding surface captured from the preview.
